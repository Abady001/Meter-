# دليل موظف خدمة العملاء

1. افتح تبويب **إدخال خدمة العملاء**.
2. تأكد من الشهر والسنة.
3. اكتب رقم العداد في الخانة الصفراء.
4. راجع اسم العميل والموقع وحالة العداد وطريقة الاحتساب والقراءة السابقة.
5. اكتب القراءة الحالية.
6. راجع فرق القراءة والاستهلاك المحسوب والاستهلاك النهائي.
7. إذا ظهرت حالة استثناء، اختر السبب الصحيح واكتب ملاحظة واضحة.
8. لا تغيّر القراءة السابقة أو جداول الخلفية يدويًا.
9. اختر **خدمة العملاء → حفظ القراءة**.
10. انتظر رسالة النجاح ورقم العملية؛ لا تضغط الحفظ مرتين.

## عند وجود مشكلة

- العداد غير موجود: راجع الرقم أو تواصل مع المشرف.
- العداد أو العميل غير نشط: لا تحفظ قراءة جديدة دون تصحيح معتمد.
- فرق القراءة سالب: اختر سبب الاستثناء الصحيح؛ قد تحتاج موافقة.
- استهلاك يدوي: أدخل القيمة والسبب؛ يحتفظ النظام بالقيمة المحسوبة منفصلة.
- قراءة مكررة لنفس الشهر: لن يسمح النظام بالحفظ؛ راجع سجل القراءات.

## تقرير الشهر

1. افتح **تقرير الشهر**.
2. اختر الشهر والسنة والمرشحات المطلوبة.
3. اختر **خدمة العملاء → تحديث تقرير الشهر**.
4. راجع القراءات الناقصة والاستثناءات والإجماليات.
5. اختر **استخراج تقرير الشهر PDF** بعد اعتماد الأرقام.
6. شارك ملف التقرير فقط، ولا تشارك جداول الإعدادات أو التدقيق أو الملاحظات الداخلية.
